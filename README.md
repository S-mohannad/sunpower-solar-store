## 📋 نظرة عامة

متجر إلكتروني احترافي لبيع منتجات الطاقة الشمسية في العراق — يشمل ألواح شمسية، بطاريات، عواكس، وباقات متكاملة، مع واجهة عربية RTL كاملة وتصميم Glassmorphism عصري.

---

## ✨ المميزات

- ☀️ **صفحة رئيسية** — عرض المنتجات والخدمات بتصميم احترافي
- 🛒 **صفحة المنتجات** — ألواح، بطاريات، عواكس، وباقات مع نظام سلة مشتريات
- 💳 **نظام الطلب** — خطوات واضحة مع خيارات دفع متعددة
- 🛡️ **صفحة الضمانات** — عرض ضمانات المنتجات مع FAQ تفاعلي
- 📞 **صفحة التواصل** — نموذج تواصل مع خريطة وبيانات الفريق
- 📱 **متجاوب مع الموبايل** — يعمل على جميع الأجهزة
- 🌐 **دعم كامل للعربية** — RTL، خط Cairo، تصميم من اليمين لليسار
- 🎨 **Glassmorphism** — تأثيرات زجاجية عصرية
